# used-car-price-prediction
Pythonを用いた中古車価格予測。前処理・特徴量作成・モデル比較を実施。
# 中古車価格予測

## 目的
トヨタの中古車データを用いて、年式・走行距離・車種などの情報から販売価格を予測するモデルを構築しました。予測精度の比較に加え、特徴量の追加による変化や、誤差が大きくなる車の傾向を確認することを目的としています。

## 使用技術
- Python
- pandas、NumPy：データの加工・集計
- Matplotlib：データと評価結果の可視化
- scikit-learn：前処理、モデル構築、交差検証

## 取り組んだ内容
- 欠損値と重複行を確認し、完全一致する重複行を削除
- カテゴリ列の前後の空白を除去
- 価格分布や、数値特徴量と価格の相関を可視化
- 年式・走行距離・排気量・税額・燃費を数値特徴量として使用
- 車種・変速機・燃料種別をOne-Hotエンコーディング
- Pipelineで前処理と学習をまとめ、各学習データ内で前処理を実施
- 中央値を使うベースラインと、線形回帰・Ridge・Lasso・ランダムフォレストを比較
- カテゴリ特徴量を段階的に追加し、予測精度への影響を比較
- 検証データでのMAEと、5分割交差検証による平均MAE・標準偏差を算出
- 実測値と予測値、残差を可視化し、車種別・価格帯別の誤差を集計

## 結果・考察
評価指標には、予測価格と実際の価格の差を平均したMAEを使用しました。価格の単位は英国ポンドです。

- ランダムフォレストの検証MAE：744.03 GBP
- 5分割交差検証の平均MAE：778.01 GBP
- 分割間のMAEの標準偏差：23.83 GBP
- 中央値ベースラインに対する平均MAE削減率：82.6 ％

モデル全体の精度だけでなく、特徴量の追加による精度の変化や、車種・価格帯ごとの誤差を確認できるようにしました。

今後は、誤差の大きい車に共通する特徴の調査や、特徴量重要度の確認を進め、予測の根拠を説明できる分析を目指します。また、モデル選択に使用しないテストデータを確保し、最終的な性能を評価することも改善点です。
